# CV Web & PDF - Tiziano Ariel Cavia Peretti

Este proyecto contiene el Currículum Vitae moderno, interactivo y optimizado para impresión de **Tiziano Ariel Cavia Peretti**, enfocado en su postulación a **Primer Empleo en Heladerías / Gastronomía y Atención al Público**.

---

## 📁 Archivos incluidos

1. **`index.html`**: Sitio web interactivo completo.
   - Diseño moderno, responsivo (se adapta a celulares y PC).
   - Botón directo de **WhatsApp** con mensaje preconfigurado para el empleador.
   - Botón de **Descargar / Imprimir en PDF**.
   - Botón de **Compartir**.
   - Código QR dinámico integrado en el pie de página.
   - Calibrado con CSS `@media print` para que al imprimir salga en **1 sola carilla A4 exacta**.

2. **`CV_Tiziano_Cavia_Peretti.pdf`**: El archivo PDF ya generado, listo para enviar por WhatsApp o llevar a imprimir en una librería.

3. **`cv_preview.png`**: Vista previa en imagen de alta resolución del CV final.

4. **`qrcode.min.js`**: Librería liviana para renderizar el código QR sin depender de conexión a internet.

## 🚀 Cómo publicarlo en GitHub Pages (Gratis en 3 minutos)

Para que Tiziano tenga su propio link online (ej: `https://tu-usuario.github.io/cv-tiziano/`):

### Opción A: Desde la web de GitHub (Sin instalar nada)
1. Entrá a [github.com](https://github.com) y creá un nuevo repositorio (por ejemplo: `cv-tiziano`), seleccionando que sea **Público**.
2. Hacé clic en **"Add file" -> "Upload files"**.
3. Arrastrá los archivos de esta carpeta (`index.html`, `qrcode.min.js`, etc.) y confirmá con **Commit changes**.
4. En el repositorio, andá a **Settings -> Pages**.
5. En la sección **Branch**, seleccioná `main` (o `master`) y la carpeta `/(root)`, luego hacé clic en **Save**.
6. ¡Listo! En 1 minuto GitHub te dará el enlace público web para enviarle a Tiziano.
